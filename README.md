# Doo

**Simplesssssst TODO App**

A lightweight macOS todo list — one list per day, saved as Markdown.

## Features

- Daily todos, one list per day
- Incomplete items carry over to the next day
- Stored locally in `todos.md`, plain and editable
- Pin the window to keep it on your desktop

## Development

Open `doo.xcodeproj` in Xcode and run the **Doo** scheme.

Requires macOS and Xcode.

## Data

```
~/Library/Application Support/mux.doo/todos.md
```

Use **Show Storage Folder** in the menu (`⌘⇧O`) to open it quickly.

Example:

```markdown
## 2026-06-09
- [ ] Write README
- [x] Ship it

## 2026-06-10
- [ ] Finish yesterday's task
```
